# Branch-Only ASIC Power Research Evidence

This directory is a sanitized, machine-readable record of a bounded automatic
clock-gating evaluation. Its classification is `NEGATIVE / NOT_PROMOTED /
PHYSICALLY_BLOCKED`. It is branch-only research evidence, not a verified `main`
claim, a release result, or a production-profile change.

`points.csv` is the sole numeric authority. `comparisons.csv` is a derived file:
the branch-only validator regenerates it with `Decimal` arithmetic and requires
byte-for-byte equality. `verification.csv` binds required ModelSim/Questa
markers and normalized functional trace hashes. `physical_attempts.csv` keeps
the stopped physical boundary, while `physical_artifacts.csv` publishes only
logical IDs, sizes, and SHA-256 values for artifacts that are not distributed.

The fixed-revision, parameter, tool, library, workload, activity, gating, and
nonclaim contracts are in `manifest.json`. `hashes.sha256` is regenerated by
the validator and covers every published payload file in this directory.

The package contains no raw commercial logs or reports, netlists, DDC, SDC,
ODB, SPEF, VCD, SAIF, library payload, host, account, license, or local-path
data. It does not support a complete-DMA, SRAM, maximum-frequency, CTS
clock-tree, post-route paired-power, LEC/Formality, foundry, or silicon
conclusion.

Run from the repository root:

```text
make power-research-check
```
