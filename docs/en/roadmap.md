# Roadmap

Next work is profile-specific: complete independent true-pulse characterization
for the 256x128 and 64x128 SRAMs before any C4B4 SRAM run; add power estimation
and IO/OCV/MMMC analysis to the C2 implementation; complete CDC/RDC, lint,
formal, and DFT closure; then validate board-level 10G integration and software
recovery separately. Generic `SL_DATA_WIDTH` parameterization and a 128-bit
standard profile remain future functional work.
